# 📊 Electronics Sales Analysis

## 📌 Project Overview

This project analyzes sales data from a multi-product electronics retail store, including mobile phones and accessories. The goal is to uncover trends, understand customer behavior, and generate actionable business insights.

## 🎯 Objectives

* Identify top-selling products
* Analyze sales trends over time
* Understand customer purchasing patterns
* Evaluate promotional strategies

## 🛠️ Tools & Technologies

* Python (Pandas, NumPy)
* Data Visualization (Matplotlib / Seaborn)

## 📈 Key Insights

* Sales peak during seasonal periods
* Majority revenue comes from retail (B2C) customers
* Android devices dominate in volume, while premium products generate higher value
* Promotional giveaways do not always increase sales

* Dataset (cleaned & processed)
* Jupyter Notebook (analysis & visualization)
